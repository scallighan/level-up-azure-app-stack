# 06 Copilot and Teams Integration
* Run Terraform
* In `appPackage` copy `env.sample` to `.env` update the values
* In `appPackage` run `./publish.sh` and locate the `build/appPackage.aca.zip`
* Naviage to https://dev.teams.microsoft.com/
* Select Import an app
* Import `appPackage.aca.zip` 
* Go to "Publish to org" and submit for your organization
* PIM to a global admin
* Navigate to `https://admin.cloud.microsoft/?#/homepage`
* Agents -> AllAgents
* Requests
* Approve your bot
* Navigate to `https://m365.cloud.microsoft/`
* Search for your agent and try it out
